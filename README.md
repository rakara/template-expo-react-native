# Expo React Native Starter

Production-oriented starter for cross-platform iOS and Android applications.

## Stack

- Expo, React Native and Expo Router
- TypeScript (strict)
- Supabase Auth and PostgreSQL
- Expo SecureStore, TanStack Query, Zustand and Zod
- Jest, jest-expo and React Native Testing Library
- npm and EAS Build

## Status

Initial repository bootstrap. See `TASKS.md` for implementation status and `docs/` for architecture, development, deployment, environment and security guidance.

## Quick start

The complete setup instructions will be maintained here as implementation lands. Copy `.env.example` to `.env`, configure a Supabase project, then install dependencies with `npm ci`.

## Scope

Includes native navigation, secure session persistence and real Supabase authentication. No fake users, mocked API responses, or hard-coded credentials.
