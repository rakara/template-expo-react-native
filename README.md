# Expo React Native Starter

Production-oriented cross-platform iOS and Android starter using Expo Router, TypeScript and Supabase.

## Setup

1. Copy `.env.example` to `.env` and configure a Supabase project.
2. Run `npm install`.
3. Run `npx expo start` and open on a development device.

Use EAS Build for native release builds. See `docs/` and `TASKS.md`. No demo credentials or fake users are included.
